## ✨ Обо мне

Я создаю ботов и CLI-утилиты, которые превращают внешние события в понятные уведомления, экраны, загрузки и повторяемые рабочие процессы. Среди публичных репозиториев есть как небольшие прототипы, так и многомодульные приложения; README каждого проекта отдельно описывает настройку, данные и текущие ограничения.
